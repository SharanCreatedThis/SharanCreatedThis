# Charm content requirements

_Generated on 2026-09-25._

Which charms could carry a standalone page, which belong only on a collection page, and which should never be indexed.

**The 600-word rule:** a charm earns a page when 600 honest words of origin, meaning and variation exist for it. No charm currently has any authored content, so the third column is an assessment of *available* subject matter, not of work done.

## Rules applied

1. **Licensed → never indexable.** Eight collections are someone else's IP. No authored copy changes this.
2. **No display name → cannot be listed at all**, let alone given a page.
3. **Standalone page** requires a subject with a documented tradition — something a reader could look up independently.
4. Everything else belongs on a collection page.
